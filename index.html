📲 Cara Install di HP Android

atau ikuti langkah manual di bawah

1

Buka di Chrome

Pastikan file ini dibuka menggunakan browser Chrome di HP Android.

2

Ketuk menu tiga titik

Di pojok kanan atas Chrome, ketuk ikon tiga titik vertikal (⋮) untuk membuka menu.

⋮ Menu di pojok kanan atas
3

Pilih "Tambahkan ke layar utama"

Cari dan ketuk opsi "Tambahkan ke layar utama" atau "Add to Home Screen".

Tambahkan ke layar utama
4

Konfirmasi & Install

Ketuk "Tambahkan" atau "Install" pada popup yang muncul. Ikon TK Report akan muncul di layar utama HP.

✅ Siap dipakai offline

💡 Catatan: Setelah diinstall, aplikasi bisa dibuka langsung dari layar utama HP tanpa perlu internet. Data tersimpan di HP masing-masing mandor.
